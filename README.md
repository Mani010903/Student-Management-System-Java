

# Student Management System

A full CRUD desktop application built in Java for managing student records, supporting add, view, update, delete, and search functionality for 500+ records.

## Features
- Full CRUD operations (Create, Read, Update, Delete)
- Search functionality across student records
- Modular backend architecture following OOP principles
- Built across all SDLC phases from design to deployment

## Tech Stack
Java, JDBC, MySQL

## Setup
\`\`\`bash
git clone https://github.com/Mani010903/Student-Management-System-Java.git
cd Student-Management-System-Java
# Set up MySQL database using schema.sql (if included)
# Update DB credentials in the config file
# Compile and run via your IDE (e.g., Eclipse) or:
javac Main.java
java Main
\`\`\`
