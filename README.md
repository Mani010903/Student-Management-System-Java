# Student Management System 🎓

A Java-based Student Management System that allows users to manage student records efficiently through a menu-driven interface. The application supports CRUD operations, sorting, searching, pagination, and data validation to simplify student record management.

## 📌 Project Overview

The Student Management System is designed to store and manage student information such as name, age, department, and marks. It provides an interactive console-based interface for performing various operations on student records.

The project also includes a Swing-based graphical user interface (GUI) implementation that is currently under development.

## 🚀 Features

* Add new students
* View all students
* Search students by ID
* Search students by name
* Search students by department/course
* Update student details
* Delete student records
* Sort students by:

  * Name
  * Age
  * Marks
  * ID
  * Department
* Pagination support for large datasets
* Input validation and error handling
* Colored terminal output for better readability
